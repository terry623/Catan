## 啟動

```bash
python3 main.py
```

不需要安裝任何套件，純 Python 3 標準庫。

## 規則

完整實作卡坦島桌遊規則：

- **地圖**: 19 格六角地圖，隨機地形與數字
- **建設階段**: 蛇形選位（1→2→3→4→4→3→2→1），每人放 2 聚落 + 2 道路
- **回合流程**: 擲骰子 → 資源分配 → 交易 → 建造
- **建築**: 道路、聚落、城市
- **資源**: 磚塊、礦石、羊毛、麥子、木材
- **交易**: 銀行 4:1、港口 3:1 / 2:1、與電腦玩家交易
- **強盜**: 擲出 7 時，手牌 >7 棄一半，移動強盜，偷取資源
- **發展卡**: 騎士、勝利點數、築路、豐收年、壟斷
- **特殊獎勵**: 最長道路（5+）、最大騎士團（3+）
- **勝利條件**: 先達 10 勝利點數

## 建築費用

| 建築 | 費用 | 效果 |
|------|------|------|
| 道路 | 磚×1 木×1 | 擴展路網 |
| 聚落 | 磚×1 木×1 毛×1 麥×1 | +1 VP |
| 城市 | 麥×2 礦×3 | +2 VP（升級聚落） |
| 發展卡 | 礦×1 毛×1 麥×1 | 各種效果 |
